## タイトル案

**推奨**

```
シフトが組めない週に「組めない」と言うAIを作った — ゆずる条件はAIが決め、組めるかは計算が確かめる
```

前半で「組めないと言うAI」まで読めるので、スマホで末尾が切れても意味が通る。

**別案**

```
AIに何を任せて、何を任せないか — シフト作成エージェント kumu
```

```
「ここで止める」と言えるAIを作った｜シフト作成エージェント kumu
```

## 説明文

```
飲食店のシフトを作るAI「kumu」のデモです。
どう並べても人が足りない週には、シフトを出さずに「組めません」と返します。

この作品の中心は、AIに何を任せて、何を任せないかの線引きです。

並べ方そのものを探す仕事はAIに向いていないので、パズルを解く専用の計算にやらせています。
かわりにAIには、決まりでは書けない仕事を任せました。人が書いた文章を読むこと、
組めなかったときにどの決まりからゆずるかを決めること、希望欄に混ざった攻撃を見つけること。
どれも毎回中身が違うので、決まりとして先に書いておけません。

AIが決めたことは、そのまま実行しません。言ったことが本当かは計算が確かめ、
やってよいかは店長が決めます。AIは「ここで止める」とも言えます。

章立て
0:00 希望を出す
0:12 全員のシフト
0:36 組めない週
0:56 AIがゆずる条件を決める
1:37 確認待ち（希望欄に混ざった指示文）
2:03 自分のシフト
2:09 代われる人を探す

作りはじめたときは「AIにシフトは作れない」と考えていました。
測ったら間違いで、6回のうち2回は制約違反ゼロで組めています。
ただし同じ条件でも、1回目は違反11件、3回目は1件。守れているかは出してみるまで分かりません。
希望をどれだけ通せたかは、AIが42〜53%に対して計算が70%でした。
この測定が、上の線引きの根拠になっています。

リンク
GitHub: https://github.com/muroshima/kumu
記事: （Qiita の URL）

AI HACK 2026 提出作品です。店もスタッフも架空で、実在のデータは使っていません。

使ったもの
OR-Tools CP-SAT / OrcaRouter / Python / Playwright + edge-tts + ffmpeg
（この動画も画面録画ソフトを使わず、スクリプトで生成しています）
```
